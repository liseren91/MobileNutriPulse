# Структура iOS проекта NutriPulse

## ✅ Что было создано

### Модели данных (`Models/`)
- `Models.swift` - все структуры данных (UserProfile, Meal, Ingredient, ChatMessage, ViewState)

### Сервисы (`Services/`)
- `GeminiService.swift` - интеграция с Google Gemini API для генерации планов питания и чата
- `StorageService.swift` - сохранение и загрузка данных через UserDefaults

### Views (`Views/`)
- `OnboardingView.swift` - экран онбординга (4 шага настройки)
- `DashboardView.swift` - главный экран с таймером до следующего приема пищи
- `MealListView.swift` - список блюд с детальной информацией
- `ShoppingListView.swift` - список покупок с возможностью исключения продуктов
- `ChatCoachView.swift` - чат с AI-диетологом
- `NavigationView.swift` - нижняя навигационная панель

### Основные файлы
- `NutriPulseApp.swift` - точка входа приложения и AppState
- `ContentView.swift` - главный view с роутингом
- `Info.plist` - конфигурация приложения (API ключ)

## 🔑 Ключевые особенности реализации

1. **SwiftUI** - полностью нативный UI
2. **Async/Await** - современный подход к асинхронным операциям
3. **UserDefaults** - простое хранилище данных
4. **EnvironmentObject** - управление состоянием через AppState
5. **Многоязычность** - встроенная поддержка ru/en

## 📱 Функциональность

- ✅ Онбординг с настройкой профиля
- ✅ Таймер питания с учетом режима сна
- ✅ Генерация плана через Gemini AI
- ✅ Просмотр рецептов
- ✅ Список покупок
- ✅ Чат с диетологом
- ✅ Уведомления о времени приема пищи
- ✅ Исключение нежелательных продуктов

## 🚀 Следующие шаги

1. Откройте проект в Xcode
2. Добавьте все файлы в проект (см. SETUP.md)
3. Установите API ключ Gemini в Info.plist
4. Соберите и запустите проект
