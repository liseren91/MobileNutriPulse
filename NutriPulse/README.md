# NutriPulse iOS

Нативное iOS приложение для планирования питания с использованием Google Gemini AI.

## Требования

- Xcode 15.0 или новее
- iOS 17.0 или новее
- Swift 5.9+
- Google Gemini API ключ

## Установка

1. **Клонируйте репозиторий** или откройте проект в Xcode

2. **Настройте API ключ Gemini:**
   - Откройте `NutriPulse/NutriPulse/Info.plist`
   - Найдите ключ `GEMINI_API_KEY`
   - Замените `YOUR_API_KEY_HERE` на ваш реальный API ключ от Google Gemini
   
   Или установите через переменную окружения:
   ```bash
   export GEMINI_API_KEY="ваш_ключ_здесь"
   ```

3. **Откройте проект в Xcode:**
   ```bash
   open NutriPulse/NutriPulse.xcodeproj
   ```

4. **Выберите симулятор или устройство** и нажмите Run (⌘R)

## Функциональность

### ✨ Основные возможности

- **Онбординг** - настройка профиля пользователя
- **Таймер питания** - отслеживание времени до следующего приема пищи
- **Генерация плана** - создание 3-дневного плана питания через Gemini AI
- **Список блюд** - просмотр рецептов с ингредиентами и инструкциями
- **Список покупок** - автоматически сгенерированный список продуктов
- **Чат с диетологом** - общение с AI-консультантом
- **Уведомления** - напоминания о времени приема пищи
- **Многоязычность** - поддержка русского и английского языков

### 🎨 Особенности

- Нативный SwiftUI интерфейс
- Адаптивный дизайн для iPhone
- Сохранение данных в UserDefaults
- Интеграция с Google Gemini API
- Поддержка темной темы iOS

## Настройка API ключа

### Способ 1: Через Info.plist (рекомендуется)

1. Откройте `NutriPulse/NutriPulse/Info.plist`
2. Найдите строку:
   ```xml
   <key>GEMINI_API_KEY</key>
   <string>YOUR_API_KEY_HERE</string>
   ```
3. Замените `YOUR_API_KEY_HERE` на ваш ключ

### Способ 2: Через переменную окружения

Добавьте в схему проекта (Edit Scheme → Run → Arguments → Environment Variables):
- Name: `GEMINI_API_KEY`
- Value: `ваш_ключ`

### Получение API ключа

1. Перейдите на [Google AI Studio](https://aistudio.google.com/)
2. Войдите в аккаунт Google
3. Создайте новый API ключ
4. Скопируйте ключ и используйте его в проекте

## Сборка и запуск

1. Откройте `NutriPulse.xcodeproj` в Xcode
2. Выберите симулятор iPhone или подключите устройство
3. Нажмите ⌘R или кнопку Run
